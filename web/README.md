# web

S2: integração Next.js/TypeScript com Flask e Mongo, sem telas. Módulo comparison contém contrato Zod, cliente, caso de uso e repositório. Documentos e relatórios são persistidos pelo mesmo dono web; auth permanece sem implementação até S3. Tailwind não é necessário para estas rotas e fica para a etapa das telas.

Node 24.22.1 e versões no package-lock.json. Com esse Node no PATH: npm ci, npm test, npm run typecheck, npm run build. Execução local e preparação do modelo no README da raiz. Docker expõe só 127.0.0.1:3000. POST /api/comparisons recebe dois arquivos; GET /api/comparisons/[id] lê o registro persistido. Estas rotas são desenvolvimento local e ainda não oferecem controle de acesso por usuário.

O índice simétrico, o alinhamento e as classes direcionais são saídas distintas. Não transformar “sem correspondência detectada” em originalidade comprovada, nem apresentar classes/limiares provisórios como confiança calibrada. Configurações e contratos científicos estão nos registros privados do projeto e na resposta da API.
